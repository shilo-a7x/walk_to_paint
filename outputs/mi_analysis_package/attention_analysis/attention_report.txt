ATTENTION EFFECTIVE-DISTANCE ANALYSIS (Step 3)
================================================================================

For each masked target position i, effective_distance =
sum_j attn[i,j] * |i-j|, averaged over all sampled masked
positions in the test split (over valid, non-padded j).

Token layout alternates node/edge: 1 graph-hop = 2 token
positions, so |i-j| <= 4 <=> within 2 graph-hops.
frac_beyond_2hop = fraction of attention mass with |i-j| > 4.
