## Directory Creation Process

### Step 1: Initial Structure Created by `resolve_outputs_dirs()`

**Function:** `src/utils/paths.py::resolve_outputs_dirs()`

```python
def resolve_outputs_dirs(cfg, make_dirs=True):
    """
    Creates the canonical output structure:
    outputs/{dataset_name}/{exp_name}_{timestamp}/
      ├── checkpoints/
      ├── logs/
      ├── optuna/     ← PRE-CREATED but optional
      └── plots/      ← PRE-CREATED but optional
    """
```

**Called from:** `run.py` (line ~67)

**Timing:** Before data preparation, before training

**What it does:**

1. Resolves paths based on config
2. Creates 4 directories: checkpoints, logs, optuna, plots
3. Updates `cfg.training.checkpoint_dir` and `cfg.training.log_dir`
4. Returns dict with all paths

**Result:** Directories exist but optuna/ and plots/ remain empty (not used)

### Step 3: Model Training (PyTorch Lightning)

**Function:** `src/training/train.py::train_model()`

**Callbacks that populate directories:**

#### A) ModelCheckpoint Callback

- **Saves to:** `checkpoints/`
- **Pattern:** `{dataset}-{exp_name}-epoch={N}-val_loss={L}.ckpt`
- **Example:** `toy-toy-run-epoch=02-val_loss=3.48.ckpt`
- **When:** Every epoch, keeps best by `val_loss`
- **Count:** 3 files for 3 epochs (all kept in toy, but real training might keep only best)

#### B) TensorBoard Logger

- **Saves to:** `logs/{logger_name}/version_0/`
- **Logger name:** From config `training.logger_name` (defaults to "{dataset}-{exp_name}")
- **Creates:**
  - `events.out.tfevents.*` (binary TensorBoard events)
  - `hparams.yaml` (hyperparameters snapshot)
- **Automatically generated by PyTorch Lightning**

#### C) PerEpochPredictionSaver Callback ⭐ (NEW)

- **Saves to:** `checkpoints/{dataset}_predictions/`
- **Pattern:** `epoch_{N:03d}/{split}_predictions.pkl`
- **Timing:**
  - Train predictions: after on_train_epoch_end
  - Val predictions: after on_validation_epoch_end
  - Test predictions: after test loop in PerEpochTestRunner
- **Content:** Predictions + metadata (see TASK3_POC_COMPLETE.md)

## Why Are optuna/ and plots/ Empty?

### Short Answer

These directories are **reserved for future/optional use**, not part of the current training pipeline.

### Long Answer

#### optuna/ Directory

- **Purpose:** Would store Optuna hyperparameter optimization results
- **Files that might go here:**
  - `optuna_study.db` (Optuna database)
  - `trial_results.csv`
  - `best_params.yaml`
- **Current Status:**
  - ❌ Not used in standard training (only in `optuna_run.py`)
  - ✅ Used by separate Optuna orchestrator script
  - Pre-created for convenience when running `run.py`

#### plots/ Directory

- **Purpose:** Would store visualization outputs
- **Files that might go here:**
  - `confusion_matrix_epoch_0.png`
  - `roc_curve_train.png`
  - `metrics_over_time.png`
- **Current Status:**
  - ❌ Not used in current training loop
  - ✅ Could be populated by post-processing scripts
  - Pre-created for convenience

### Code Reference

From `src/utils/paths.py` (lines 11-19):

```python
"""
Layout (default):
  <base_outputs_dir>/<dataset.name>/<exp_name>[_<timestamp>]/
     checkpoints/        ← Used for model checkpoints
     logs/               ← Used for TensorBoard logs
     optuna/             ← For Optuna hyperparameter studies
     plots/              ← For visualization outputs
"""
```

This is **by design** - create the structure upfront so different scripts can use it independently:

- `run.py` for training
- `optuna_run.py` for hyperparameter search
- Post-hoc analysis scripts for plots

### Full Path Resolution Example

```
BASE                = "outputs"              (config.paths.base_outputs_dir)

EXP_NAME            = "toy-run"              (cfg.training.exp_name, auto-generated)

checkpoint_dir      = exp_dir/checkpoints/
log_dir             = exp_dir/logs/
optuna_dir          = exp_dir/optuna/
plots_dir           = exp_dir/plots/

checkpoint_file     = checkpoint_dir/toy-toy-run-epoch=00-val_loss=2.75.ckpt
predictions_dir     = checkpoint_dir/toy_predictions/
epoch_dir           = predictions_dir/epoch_000/
```

### Key Points

- **Dataset-scoped:** All outputs under `outputs/{dataset_name}/`
- **Timestamped:** Prevents accidental overwrites across runs
- **Hierarchical:** Each component has its own subdirectory
- **Predictable:** Pattern is deterministic and machine-readable

## Cleanup & Space Management

### What Can Be Deleted (Post-Analysis)

```bash

# TensorBoard events (after viewing in TensorBoard)
rm logs/*/version_*/events.out*

# Cache (will rebuild on next run)

```

### What Should Never Be Deleted

```bash
# Prediction files (needed for analysis)
✅ KEEP: checkpoints/toy_predictions/

✅ KEEP: logs/*/hparams.yaml
```
